# Salad Soulmates — Scheduling & Worker Mobile Update

Updated September 18, 2026.

## What changed

- Workforce scheduling and PTO moved from later scope into the core product.
- Admin scheduling includes week/day views, draft/publish, assignment conflicts, PTO and links to production work.
- Workers receive published assignments on a simplified phone experience.
- Spanish is required for the initial worker rollout and is now an explicit product/build requirement.
- The digital Batch Worksheet replacement is defined as a Spanish-first, one-step-at-a-time phone flow.
- Build Specification now uses gated increments: 1A planning/scheduling/worker shell; 1B receiving/serialization; 1C live Spanish digital Batch Worksheet + mixer execution.
